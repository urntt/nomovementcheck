# nomovementcheck

A simple server-side Fabric mod for Minecraft: Java Edition that makes the server completely trust the client on movement and position.

For the players it applies to, the server never kicks them or sets them back because of how they moved. Clients do not need the mod.

## Warning

A player this mod applies to can fly, pass through blocks, and move at any speed with a modified client, and the server will not object. Enable it only for players you trust.
